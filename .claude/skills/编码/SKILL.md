# 编码模式

## 功能说明

切换到 mimo-v2.5-pro 模型，专门用于编写和调试代码。

## 使用方式

当用户需要编写代码时，执行以下步骤：

1. 使用 Bash 工具执行：`/model mimo-v2.5-pro[1m]`
2. 提示用户："已切换到**编码模式**（mimo-v2.5-pro）。现在开始编写代码。"
3. 根据用户需求开始编写代码

## 示例对话

**用户**：编码
**助手**：执行 `/model mimo-v2.5-pro[1m]`
**助手**：已切换到**编码模式**（mimo-v2.5-pro）。现在开始编写代码。

**用户**：帮我创建 MainWindow.xaml
**助手**：[开始编写代码]

## 注意事项

- 此模式专门用于代码编写，编写完成后可使用 `/识图` 切换到识图模式
- mimo-v2.5-pro 模型的代码生成能力更强，适合编写复杂的业务逻辑和 UI 代码
