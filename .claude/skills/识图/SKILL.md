# 识图模式

## 功能说明

切换到 mimo-v2.5 模型，专门用于识别和分析设计图片。

## 使用方式

当用户需要识别图片时，执行以下步骤：

1. 使用 Bash 工具执行：`/model mimo-v2.5`
2. 提示用户："已切换到**识图模式**（mimo-v2.5）。请提供图片路径，我来帮你识别分析。"
3. 等待用户提供图片路径
4. 使用 Read 工具读取图片并进行分析

## 示例对话

**用户**：识图
**助手**：执行 `/model mimo-v2.5`
**助手**：已切换到**识图模式**（mimo-v2.5）。请提供图片路径，我来帮你识别分析。

**用户**：e:\reader\design\screen.png
**助手**：[读取图片并分析]

## 注意事项

- 此模式专门用于图片识别，识别完成后可使用 `/编码` 切换回编码模式
- mimo-v2.5 模型对图片的理解能力更强，适合分析 UI 设计稿、截图等视觉内容
